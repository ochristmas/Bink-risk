## 当前范围

本知识库用于沉淀银行系统性风险传染相关的概念、机制、方法、文献与数据口径。现阶段将“双渠道”作为工作定义：

1. **直接关联渠道**：同业拆借、支付结算、担保与衍生品等合同网络造成的直接损失传递。
2. **间接关联渠道**：共同资产持有、流动性挤兑与资产抛售等行为造成的价格冲击与损失放大。

如果项目采用不同口径，请在 [双渠道风险传染机制](docs/mechanisms/dual-channel-contagion.md) 中统一修订，并同步更新研究框架和数据字典。
