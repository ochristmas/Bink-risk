# 双渠道银行风险传染机制

> 状态：工作假设。当前采用“直接关联 + 间接关联”的双渠道定义，后续可按项目口径调整。

## 渠道一：直接关联

银行之间通过可识别的合同或清算关系形成风险暴露。

常见路径：

- 同业拆借与存放；
- 支付清算与结算头寸；
- 担保、回购与衍生品；
- 集团内部或关联方融资。

基本链条：

`初始冲击 → 债务人损失或违约 → 债权人资产减值 → 资本/流动性约束收紧 → 次生违约`

关键参数包括违约概率、违约损失率、净额结算、抵押品折扣和损失吸收能力。

## 渠道二：间接关联

银行即使没有直接合同，也可能因持有相似资产或采取相似行为而相互影响。

常见路径：

- 共同资产持有；
- 流动性需求引发的被迫抛售；
- 市场价格下跌与盯市损失；
- 融资折扣上升、保证金追加和挤兑。

基本链条：

`初始冲击 → 流动性/资本压力 → 资产抛售 → 价格下跌 → 其他银行账面损失 → 更多抛售`

关键参数包括资产重叠度、市场深度、价格冲击函数、杠杆约束和抛售规则。

## 两条渠道的反馈

两条渠道通常不是独立的：

1. 直接损失削弱资本，引发被迫抛售。
2. 资产价格下跌降低抵押品价值，放大直接信用暴露。
3. 流动性紧张提高短期融资成本，促使更多机构收缩资产负债表。
4. 多轮反馈可能产生阈值效应和非线性放大。
