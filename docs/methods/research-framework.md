# 研究框架

## 1. 明确研究问题

使用可检验的形式描述：

- 哪一种冲击？
- 通过哪条渠道传播？
- 影响哪些主体和指标？
- 在什么条件下放大或减弱？
- 需要解释机制、预测结果，还是评估政策？

示例结构：

> 当外部资产价格受到冲击时，直接同业暴露与共同资产持有如何共同影响银行系统损失分布？

## 2. 定义系统

记录样本、时间、节点、边、资产类别、系统边界和缺失数据处理方法。

## 3. 写出机制

分别描述：

- 初始状态；
- 冲击规则；
- 直接传染规则；
- 间接传染规则；
- 资本与流动性约束；
- 迭代顺序与终止条件。

## 4. 选择证据

| 目标 | 可选方法 |
| --- | --- |
| 描述网络结构 | 集中度、中心性、核心—边缘结构 |
| 评估压力传播 | 网络清算、违约级联、压力测试 |
| 评估资产抛售 | 价格冲击函数、资产重叠网络 |
| 识别因果影响 | 自然实验、面板模型、工具变量等 |
| 评估尾部联动 | 分位数、极值或条件风险度量 |
| 验证模型 | 样本外检验、历史事件回测、敏感性分析 |

## 5. 报告结果

至少报告基准情形、单渠道情形、双渠道情形、参数敏感性和主要限制。不要只报告平均损失；同时关注尾部、分布和关键节点。

## 6. 可复现性

每次研究迭代应保留：

- 数据版本和来源；
- 参数表；
- 模型版本；
- 运行日期；
- 随机种子（如适用）；
- 图表与结论的对应关系；
- 已知限制。
