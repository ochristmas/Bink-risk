## 推荐阅读顺序

1. 先阅读核心概念，确认“系统性风险”和“传染”的边界。
2. 再阅读双渠道机制，明确研究对象和反馈路径。
3. 使用研究框架把研究问题映射到模型、数据和验证方案。
4. 新增文献与数据时使用模板，确保知识可以追溯和复用。

## 条目质量标准

每个知识条目应尽量包含：

- 一句话定义；
- 适用范围与不适用范围；
- 核心机制或计算方法；
- 可验证的证据；
- 来源与访问日期；
- 与本项目的关系；
- 尚待确认的问题。

## 状态标记

- **已验证**：由多个可靠来源或项目结果支持。
- **工作假设**：当前用于建模，仍需检验。
- **待核实**：来源或适用范围不充分。
- **已弃用**：保留历史记录，但不再作为当前口径。
