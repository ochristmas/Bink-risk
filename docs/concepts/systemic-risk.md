# 系统性风险：核心概念

> 状态：工作底稿。新增结论时请附来源。

## 一句话定义

系统性风险是金融体系的关键功能因冲击、关联和反馈机制而大范围受损，并对实体经济产生显著影响的风险。

## 需要区分的概念

| 概念 | 关注点 | 与本项目的关系 |
| --- | --- | --- |
| 个体风险 | 单家银行发生损失或违约 | 是系统性风险的可能起点，但两者不等同 |
| 系统重要性 | 单个机构对系统稳定的边际影响 | 用于识别关键节点 |
| 系统脆弱性 | 系统吸收冲击的能力 | 由资本、流动性、网络结构等共同决定 |
| 风险传染 | 损失或压力从一个主体传播到其他主体 | 本项目的核心机制 |
| 共同冲击 | 多家银行同时受到同一外部冲击 | 可与传染共同发生，识别时需区分 |

## 常见测量维度

- **损失规模**：资本缺口、违约数量、资产减值。
- **尾部联动**：极端状态下机构风险的共同变化。
- **网络影响**：节点违约对其他节点和整体网络的冲击。
- **功能受损**：信贷、支付、做市等金融功能的收缩。
- **实体溢出**：融资成本、投资、就业或产出的变化。

## 分析边界

研究结论至少应说明：

1. 系统边界：银行业、金融集团或金融—实体网络。
2. 时间尺度：日内流动性、短期挤兑或中长期偿付。
3. 冲击类型：信用、市场、流动性、操作或宏观冲击。
4. 损失吸收机制：资本、准备金、抵押品、担保或政策工具。
5. 传染与共同冲击如何区分。
